# Мүмкіндіктер мен құралдар — MODX MCP

[English](CAPABILITIES.md) · [Русский](CAPABILITIES.ru.md) · [Español](CAPABILITIES.es.md) · [Deutsch](CAPABILITIES.de.md) · [Français](CAPABILITIES.fr.md) · [Українська](CAPABILITIES.uk.md) · [Қазақша](CAPABILITIES.kk.md) · [Nederlands](CAPABILITIES.nl.md) · [Polski](CAPABILITIES.pl.md)

> Ескерту: бұл аударылған қысқаша шолу. 192 MCP құралының барлық параметрлер кестесі әзірге ағылшын және орыс тілдерінде қолжетімді.
1.2.4 нұсқасында 193 PHP серверлік әрекет бар, соның 192-сі 19 топтағы ашық MCP құралы. Қолжетімділік баптаулар мен орнатылған қосымшаларға тәуелді.

- Элементтер мен ресурстар: үлгілер, чанктар, сниппеттер, плагиндер, TV, санаттар және беттер.
- Ресурстардың TV мәндері мен TV өріс түрлері.
- Жүйелік баптаулар, медиа көздері және файлдар.
- Компонент коды, кодтан іздеу және тәуелділіктер графы.
- VersionX, VirtualPage, miniShop2 және MIGX — орнатылып, іске қосылса.
- Пайдаланушылар, топтар, рөлдер, саясаттар және қатынауды басқару.
- ClientConfig, қасиеттер жиындары және контекстер.
- Пакеттер, провайдерлер, атаулар кеңістіктері және лексикондар.
- Қызмет көрсету, диагностика және сайт күйін тексеру.

**Маңызды:** құрал топтарын өшіру серверлік рұқсаттарды алмастырмайды. Тікелей HTTP клиенттері стандартты Node.js клиентінің қауіпсіздік шараларын автоматты қолданбайды.

**Толық техникалық анықтамалар:** [API параметрлері (English)](https://github.com/rumata-estor/modx3-mcp/blob/main/docs/API.md) · [қауіпсіздік (English)](https://github.com/rumata-estor/modx3-mcp/blob/main/docs/SECURITY.md) · [әзірлеуші құжаттамасы (English)](https://github.com/rumata-estor/modx3-mcp/blob/main/DEVELOPMENT.md). Техникалық кестелердің толық нұсқасы әзірге ағылшын тілінде.
