# MODX MCP — мүмкіндіктер және құралдар каталогы

[English](CAPABILITIES.md) · [Русский](CAPABILITIES.ru.md) · [Español](CAPABILITIES.es.md) · [Deutsch](CAPABILITIES.de.md) · [Français](CAPABILITIES.fr.md) · [Українська](CAPABILITIES.uk.md) · [Қазақша](CAPABILITIES.kk.md) · [Nederlands](CAPABILITIES.nl.md) · [Polski](CAPABILITIES.pl.md) · [Орнату](INSTALL.kk.md) · [API анықтамалығы](API.kk.md)

**MODX MCP 1.2.5 · 198 жария құрал · 19 функционалдық топ · MODX Revolution 2.8.x / 3.x**

MODX MCP ЖИ мүмкіндігі бар MCP клиентіне әр тапсырманы тікелей SQL немесе файлдық жүйе командалары түрінде беруді талап етпей, MODX деректерімен және элементтерімен жұмыс істеуге арналған атаулы операцияларды ұсынады. Ол сайтты зерттеуді, мазмұн мен кодты өңдеуді, TV мәндерімен, пакеттермен жұмыс істеуді, қолжетімділікті басқаруды және кейбір үшінші тарап қосымшаларын қолдайды. Нақты құралдар тізімі орнатылған құрастырылымға және қосылған мүмкіндіктерге байланысты.

Бұл нұсқаулық **«MODX MCP арқылы не істей аламын?»** деген сұраққа жауап береді. Өрістердің, түрлердің, тізбеленген мәндердің толық сипаттамасы мен интеграция мәліметтерін [API анықтамалығынан](API.kk.md) қараңыз. Қосылу үшін [Орнату](INSTALL.kk.md) бөлімінен бастаңыз.

**Әсер белгілері — түсіндірмелер, рұқсат тексерулері емес.** «Оқу» конфигурация мәндері сияқты құпия деректерді де қайтара алады. «Әсері жоғары» белгісі команданы қате қолдану сайтты бұзуы немесе оның қауіпсіздігіне нұқсан келтіруі мүмкін екенін ескертеді.

## Каталогты пайдалану

Үйлесімді MCP хосты қолжетімді құралдарды анықтап, тексерілген аргументтерді жергілікті MCP клиентіне береді. Команда атауларын жаттаудың қажеті жоқ. Мысалы, беттің қалай қалыптасатынын анықтау үшін оның ресурсын тізімдеу, тағайындалған шаблонын оқу және сілтеме жасалған чанкті немесе сниппетті зерттеу қажет болуы мүмкін. Бұлар агентке міндеттелген жұмыс барысы емес, стандартты жария операциялар.

Әрекет жоқ болса, оның мүмкіндік тобы өшірілгенін, қажетті қосымша орнатылғанын және клиент/сервер нұсқалары сәйкес келетінін тексеріңіз. `modx_list_actions` орнатылған сервер қандай әрекеттерді білетінін хабарлайды.

## Қауіпсіздік туралы еске салу

`X-MCP-Token` дерегі жоғары құқықтары бар қызметтік пайдаланушының әрекеттеріне рұқсат береді. Осы құралдардың атауларын білу ғана қолжетімділік бермейді. Алайда жұмыс істейтін токенді алған шабуылдаушы PHP элементтері мен жүйелік баптауларды өзгерте алады. Бұл құжаттағы «оқу» белгісін қауіпсіздік шекарасы деп қабылдамаңыз. [Қауіпсіздік](SECURITY.kk.md) бөлімін қараңыз.

Іске асыру мәліметтерін [жария клиент анықтамаларынан](https://github.com/rumata-estor/modx3-mcp/blob/main/client/index.js) қараңыз.
