> Uwaga: to przetłumaczony przegląd. Pełne tabele parametrów wszystkich 192 narzędzi MCP są nadal dostępne po angielsku i rosyjsku.
Wersja 1.2.4 udostępnia 193 akcje PHP po stronie serwera, w tym 192 publiczne narzędzia MCP w 19 grupach. Dostępność zależy od ustawień i zainstalowanych dodatków.

- Elementy i zasoby: szablony, chunki, snippety, pluginy, TV, kategorie i strony.
- Wartości TV zasobów i typy pól TV.
- Ustawienia systemowe, źródła mediów i pliki.
- Kod komponentów, wyszukiwanie kodu i graf zależności.
- VersionX, VirtualPage, miniShop2 oraz MIGX, jeśli są dostępne.
- Użytkownicy, grupy, role, polityki i kontrola dostępu.
- ClientConfig, zestawy właściwości i konteksty.
- Pakiety, dostawcy, przestrzenie nazw i leksykony.
- Konserwacja, diagnostyka i informacje o stanie witryny.

**Ważne:** wyłączenie grup funkcji nie zastępuje autoryzacji po stronie serwera. Bezpośredni klient HTTP nie dziedziczy automatycznie zabezpieczeń oficjalnego klienta Node.js.

**Pełne dokumenty techniczne:** [parametry API (English)](https://github.com/rumata-estor/modx3-mcp/blob/main/docs/API.md) · [bezpieczeństwo (English)](https://github.com/rumata-estor/modx3-mcp/blob/main/docs/SECURITY.md) · [dla programistów (English)](https://github.com/rumata-estor/modx3-mcp/blob/main/DEVELOPMENT.md). Szczegółowe tabele techniczne są obecnie dostępne po angielsku.
