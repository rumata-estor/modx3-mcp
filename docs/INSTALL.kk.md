# MODX MCP орнату және қосу

[English](INSTALL.md) · [Русский](INSTALL.ru.md) · [Español](INSTALL.es.md) · [Deutsch](INSTALL.de.md) · [Français](INSTALL.fr.md) · [Українська](INSTALL.uk.md) · [Қазақша](INSTALL.kk.md) · [Nederlands](INSTALL.nl.md) · [Polski](INSTALL.pl.md) · [Мүмкіндіктер](CAPABILITIES.kk.md) · [API анықтамалығы](API.kk.md) · [Қауіпсіздік](SECURITY.kk.md)

MODX MCP стандартты MCP-үйлесімді ЖИ клиентіне **MODX Revolution 2.8.x және 3.x** жүйелерімен жұмыс істеуге мүмкіндік береді. Қалыпты орнату үшін MODX тасымалдау пакеті, MCP клиенті іске қосылатын компьютерде **Node.js 18+** және **stdio** MCP серверлерін іске қоса алатын қолданба қажет.

**Бөлек оркестрация сервері қажет емес.** MODX компоненті сайтыңызда HTTP API ұсынады; жергілікті `modx-mcp` процесі осы API-ді MCP клиенттеріне `stdio` арқылы қолжетімді етеді. PHP соңғы нүктесінің өзі тікелей MCP stdio сервері емес.

## 1. MODX пакетін таңдау

- **MODX 2.8.x:** `modx2mcp-1.2.4-pl.transport.zip`.
- **MODX 3.x:** `modx3mcp-1.2.4-pl.transport.zip`.

Екі нұсқа да бірдей жария құралдар келісімшартын және Node.js клиентін пайдаланады. Тиісті пакетті [GitHub Releases](https://github.com/rumata-estor/modx3-mcp/releases) бетінен немесе қолдау көрсетілетін MODX пакет провайдерінен жүктеңіз.

**Қолданыстағы MODX 2 орнатылымдары:** ескі `modxmcp` пакет сәйкестендіргішінен `modx2mcp` нұсқасына көшкенде, ескі пакетті толық жойып, содан кейін `modx2mcp` орнату ұсынылады. Толық жою ескі `modxmcp.*` баптаулары мен API токенін жояды. Қажетті конфигурацияны сақтап алып, кейін клиенттің тіркелгі деректерін жаңартыңыз. Бұдан кейінгі қалыпты `modx2mcp` жаңартулары ағымдағы токенді сақтайды.

### Басқару панелі

**Components → MODX MCP** бөлімінде API URL мекенжайын көшіріңіз, қолданыстағы токенді басқарушы тіркелгіңізде **settings** рұқсаты болғанда ғана көрсетіңіз/көшіріңіз, қосымша мүмкіндік топтарын қосыңыз не өшіріңіз және **Auto-static** / **Audit log** параметрлерін баптаңыз. Баптаулар мен мүмкіндіктерге енгізілген өзгерістер тиісті сақтау түймелері басылғаннан кейін ғана күшіне енеді. **Dependency graph** тәуелділіктер графы граф сілтемесі арқылы ашылады; оның кенебінің масштабы тінтуір дөңгелегімен өзгереді, ал айналасындағы панель сүзгілер мен мәліметтерді көрсету үшін айналдырылады. **Regenerate token** барлық қолданыстағы клиент тіркелгі деректерін жарамсыз етеді; әдеттегі пакет жаңартулары мұны істемейді. Беттегі «MCP enabled» жазуы қандай да бір нақты клиент қосылымының жұмыс істейтінін тексермейді.

## 2. Тасымалдау пакетін орнату

1. Пакеттер орнатуға рұқсаты бар тіркелгімен MODX басқару панеліне кіріңіз.
2. Пакеттерді басқару бөлімін ашып, MODX негізгі нұсқаңызға сәйкес тасымалдау ZIP файлын жүктеп, орнатыңыз.
3. MODX MCP компонентін немесе `modxmcp` атаулар кеңістігіндегі жүйелік баптауларды ашыңыз.
4. `modxmcp.api_token` және желілік шектеулерді тексеріңіз. Жаңа орнатылымдарда `modxmcp.enabled = 0` болады; қолжетімділікті қорғағаннан кейін компонентті қолмен қосыңыз.
5. Токенді **MCP клиентінің конфигурациясына** көшіріңіз. Оны жария мысал емес, құпия дерек ретінде қарастырыңыз.

Баптау бос болса, орнатушы криптографиялық кездейсоқ токен жасайды. Қалыпты жаңарту қолданыстағы токенді сақтайды.

## 3. Сайттың соңғы нүктесін табу

Стандартты URL:

```text
https://example.com/assets/components/modxmcp/api.php
```

Өз доменіңізді пайдаланыңыз; стандартты емес орналастыруларда нақты жол өзгеше болуы мүмкін. **HTTPS** ұсынылады және әдепкіде міндетті.

`GET` аутентификациясыз компонент/нұсқа туралы шектеулі жұмыс күйі жауабын қайтарады. Әкімшілік сұраулар `X-MCP-Token` бар JSON `POST` пайдаланады.

## 4. MCP хостын баптау

ЖИ қолданбасы іске қосылатын компьютерге npm/`npx` бар **Node.js 18+** орнатыңыз. MCP серверін хост конфигурациясына қосыңыз (оның орналасуы мен қолдайтын пішімі қолданбаңызға байланысты):

```json
{
  "mcpServers": {
    "modx": {
      "command": "npx",
      "args": [
        "-y",
        "github:rumata-estor/modx3-mcp#v1.2.4"
      ],
      "env": {
        "MODX_MCP_SITE_URL": "https://example.com/assets/components/modxmcp/api.php",
        "MODX_MCP_TOKEN": "YOUR_SITE_PRIVATE_TOKEN"
      }
    }
  }
}
```

`MODX_MCP_SITE_URL` — PHP HTTP API соңғы нүктесі. `MODX_MCP_TOKEN` — дәл осы сайттың токені. Өндірістік жүйелерде `main` тармағын бақылаудың орнына **жарияланған шығарылым тегін** бекітіңіз. Хостыңыз жергілікті MCP серверін `stdio` арқылы іске қосуды қолдайтынына көз жеткізіңіз.

## 5. Қосылымды тексеру

MCP интеграциясын қайта іске қосыңыз немесе хост серверлерін жаңартыңыз. `modx` серверін және `modx_` префиксі бар құралдарды іздеңіз. Тек оқуға арналған сұраудан бастаңыз, мысалы:

```text
Show the MODX version and an overview of the site structure. Make no changes.
```

Бұл үшін `modx_system_info` және `modx_project_overview` пайдаланылуы мүмкін. Сервер құрастырылымына, өшірілген топтарға және орнатылған қосымшаларға байланысты хостыңызда 192-ден аз құрал көрсетілуі мүмкін.

[Жүйелік баптаулардың толық анықтамалығы](SETTINGS.kk.md) **барлық 16 баптауды**, әдепкі мәндерді, жұмыс тәртібін және қауіпсіздік салдарын сипаттайды.

## 6. Қарап шығатын қауіпсіздік баптаулары

| Баптау | Мағынасы |
| --- | --- |
| `modxmcp.enabled` | API-ді қосу немесе өшіру. |
| `modxmcp.api_token` | API-ге қол жеткізудің құпия дерегі. |
| `modxmcp.require_https` | HTTPS талап ету; әдепкіде қосулы. |
| `modxmcp.allowed_ips` | IP мекенжайлары мен IPv4 CIDR ауқымдарының міндетті емес рұқсат тізімі; бос болса, кез келген көзге рұқсат беріледі. |
| `modxmcp.trust_proxy_https` | Кері проксидің HTTPS тақырыбына тек дұрыс бапталған прокси артында ғана сену. |
| `modxmcp.disabled_groups` | Кейбір құрал топтарын өшіру; **қауіпсіздік рөлдерінің шекарасы емес**. |
| `modxmcp.allow_run_processor` | MODX процессорын тікелей шақыруға рұқсат беру; әдепкіде өшірулі. |
| `modxmcp.max_payload_bytes` | Сұрау өлшемінің шегі. |
| `modxmcp.debug` | Қате мәліметтері; өндірістік ортада өшірулі ұстаңыз. |

**Маңызды:** сұраулар `sudo` құқықтары бар MODX қызметтік пайдаланушысының атынан орындалады. Жарамды токеннің таралуы әкімшілік өзгерістер жасауға және элементтердегі орындалатын PHP кодын өзгертуге мүмкіндік беруі мүмкін. [Қауіпсіздік нұсқаулығын](SECURITY.kk.md) оқыңыз.

## Ақауларды жою

| Белгісі | Тексеріңіз |
| --- | --- |
| MCP сервері іске қосылмайды | Node.js 18+, `npx`, пакетті табу/жүктеу және хост конфигурациясы. |
| `401 Unauthorized` | `MODX_MCP_TOKEN` мәні `modxmcp.api_token` мәніне сәйкес болуы керек; токеннің ауыстырылғанын тексеріңіз. |
| `403` | Компонентті қосу баптауы, HTTPS, кері прокси конфигурациясы және рұқсат етілген IP. |
| `404` | Соңғы нүкте жолы, компоненттің орнатылуы және веб-сервердің бағыттауы. |
| `413` | Сұрау `modxmcp.max_payload_bytes` шегінен асты. |
| Құрал қолжетімсіз | Клиент/сервер нұсқалары, өшірілген топтар, қажетті қосымшаның орнатылуы. |
| `500` | MODX қате журналдары мен `error_id`; жөндеу хабарларын жария көрсетпеңіз. |

API токендерін сұрау жолдарына немесе қате туралы есептерге қоспаңыз. Арнайы HTTP клиенттері `X-MCP-Token` тақырыбын TLS арқылы жіберуі керек.
