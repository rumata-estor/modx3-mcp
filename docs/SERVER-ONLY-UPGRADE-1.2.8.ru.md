# 1.2.8: обязательная совместимость обновления

Релизный блокер: существующий пользователь 1.2.7 должен обновить только транспортный пакет MODX 2/3. Никаких обязательных обновлений Node-клиента, Python, proc_open, новых расширений, ручных миграций или конфигурации хостинга. Проверять неизменённым клиентом 1.2.7, а не тестовой обёрткой, добавляющей CAS.

## Контракт

Для обычного существующего режима восстановить совместимость запросов без новых CAS-полей. Явно переданные предусловия проверять строго, неверные или устаревшие отклонять; отсутствие предусловий не подменять свежим снимком. В защищённом режиме сохранять обязательные CAS и независимую авторизацию. Не возвращать старый незащищённый диспетчер. Сохранить общую блокировку, ревизии, транзакции, проверки путей, ACL, токенов, ограничение процессоров и неопределённого результата.

Отдельно проверить TV, медиа, ACL, свойства, статические файлы и другие новые обязательные поля. Не обещать полной совместимости до проверки этих маршрутов. Если старый клиент не передаёт наблюдаемое состояние, конфликт с изменением до начала записи может остаться незамеченным; документировать это явно. Не ослаблять независимую авторизацию или защиту путей ради совместимости. CAS не заменяет авторизацию.

## Критерий приёмки

Реальное обновление 1.2.7 -> кандидат на MODX 2/3; неизменённый Node-клиент 1.2.7 и прежние HTTP-запросы; чтение и обычные записи, TV, медиа, ACL, сохранение настроек и токена. Проверить отказ при неправильном явном CAS, обязательность CAS и разрешений в protected mode, работу без внешних процессов. Никакой новой публикации до выполнения критерия. Beta 4 не удовлетворяет этому критерию, даже при зелёной прежней матрице.
