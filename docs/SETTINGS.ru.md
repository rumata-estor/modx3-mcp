# Системные настройки MODX MCP

[English](SETTINGS.md) · [Русский](SETTINGS.ru.md) · [Español](SETTINGS.es.md) · [Deutsch](SETTINGS.de.md) · [Français](SETTINGS.fr.md) · [Українська](SETTINGS.uk.md) · [Қазақша](SETTINGS.kk.md) · [Nederlands](SETTINGS.nl.md) · [Polski](SETTINGS.pl.md) · [Установка](INSTALL.ru.md) · [Безопасность](SECURITY.ru.md)

Справочник для **MODX MCP 1.2.4** (MODX 2.8.x и 3.x). Он описывает все **16 системных настроек**, создаваемых обоими транспортными пакетами. Источник значений по умолчанию: `_build/data/transport.settings.php`, поведение сверено с PHP-кодом.

В менеджере: **Система → Системные настройки**, пространство имён `modxmcp`. В **Компоненты → MODX MCP** доступны настройки аудита и авто-статики, переключатели групп и безопасный просмотр токена. Остальные параметры меняются через системные настройки. После изменений при необходимости обновите кэш MODX и список инструментов клиента.

**Внимание:** запросы с действующим токеном исполняются от имени sudo-пользователя MODX. Токен — секрет; группы инструментов не обеспечивают разграничения полномочий.

## Подключение и учётная запись

| Настройка | По умолчанию | Значения и действие |
| --- | --- | --- |
| `modxmcp.enabled` | `0` | `0` — POST API отклоняются; `1` — API включён. Ограниченный `GET` со сведениями о версии доступен и при `0`, если выполнено требование HTTPS. Включайте после настройки доступа. |
| `modxmcp.api_token` | Пусто в пакете; случайный токен генерируется при установке, если его нет | Непустая секретная строка для заголовка `X-MCP-Token`. Неверный токен даёт `401`. При обычном обновлении сохраняется. В панели доступны «Показать» и «Скопировать» с правом `settings`. Перевыпуск потребует обновить клиентов. |
| `modxmcp.service_user_id` | `0` | `0` — первый по ID **активный sudo-пользователь** MODX; положительное число — ID существующего активного sudo-пользователя. Рекомендуется выделенная учётная запись. Это не ID MCP-клиента. |

## Сеть и безопасность

| Настройка | По умолчанию | Значения и действие |
| --- | --- | --- |
| `modxmcp.require_https` | `1` | `0`/`1`. При `1` API требует HTTPS даже для проверки `GET`; иначе `403`. На рабочих сайтах оставьте включённым. |
| `modxmcp.trust_proxy_https` | `0` | `0`/`1`. При `1` заголовок `X-Forwarded-Proto: https` учитывается как подтверждение HTTPS. Разрешайте только за доверенным прокси, который сам формирует этот заголовок и удаляет пользовательский. |
| `modxmcp.allowed_ips` | Пусто | Список через запятую: точные IP или **IPv4 CIDR** (например, `203.0.113.5,198.51.100.0/24`). Пустая строка не ограничивает IP. Проверяется `REMOTE_ADDR`, а не `X-Forwarded-For`; точный IPv6 поддерживается, IPv6 CIDR — нет. Ошибка в списке приводит к `403`. |
| `modxmcp.disabled_groups` | `versionx,virtualpage,minishop2,migx,access,property_sets,contexts,package_management,namespaces,lexicon` | Через запятую перечисляются отключённые группы. Возможные ключи: `versionx`, `virtualpage`, `minishop2`, `migx`, `clientconfig`, `access`, `property_sets`, `contexts`, `package_management`, `namespaces`, `lexicon`. Пусто — все поддерживаемые группы доступны. **Не является границей прав доступа**; базовые операции могут менять сайт. |
| `modxmcp.allow_run_processor` | `0` | `0`/`1`. Разрешает универсальный вызов процессоров MODX, в том числе пользовательских. Расширяет права операций — оставляйте `0`, если эта функция не требуется. |
| `modxmcp.allow_root_filesystem_read` | `0` | `0`/`1`. Открывает просмотр и чтение корневого медиаисточника `Filesystem`. Расширяет доступ к файлам сервера; по умолчанию безопаснее `0`. |
| `modxmcp.component_code_roots` | `core/components,assets/components` | Каталоги через запятую — относительные от `base_path` или абсолютные, в том числе с подстановками `{core_path}`, `{assets_path}`, `{base_path}`. Области изучения кода компонентов, **не** общая файловая песочница. Не задавайте корень сервера без необходимости. |

## Ограничения

| Настройка | По умолчанию | Значения и действие |
| --- | --- | --- |
| `modxmcp.max_payload_bytes` | `1048576` (1 МиБ) | Максимальный размер JSON-запроса POST в байтах; превышение — `413`. Значение `<=0` снимает эту проверку. Рекомендуется положительный лимит. |
| `modxmcp.max_read_bytes` | `262144` (256 КиБ) | Максимальный возвращаемый фрагмент при чтении файла; `<=0` возвращает лимит 262144. **Не** общий предел размера файла: поддерживаются `offset` и `bytes`/`length`. |

## Работа и диагностика

| Настройка | По умолчанию | Значения и действие |
| --- | --- | --- |
| `modxmcp.auto_static` | `0` | `0`/`1`. При `1` создаваемые/обновляемые через MCP чанки, сниппеты, шаблоны и плагины переводятся в файлы под `core/elements/`. Нужны права на запись, резервные копии и понятная схема развёртывания. |
| `modxmcp.audit_log` | `1` | `0`/`1`. Записывает поддерживаемые операции изменения в журнал MODX и `core/components/modxmcp/logs/audit.log`. Это **не** полный журнал всех запросов. На рабочем сайте рекомендуется `1` с контролем доступа и объёма журнала. |
| `modxmcp.debug` | `0` | `0`/`1`. При `1` HTTP-ответ может содержать подробности внутренних исключений. При `0` клиент получает общую ошибку и `error_id`. В продакшене оставьте `0`. |

## Путь компонента

| Настройка | По умолчанию | Значения и действие |
| --- | --- | --- |
| `modxmcp.core_path` | `{core_path}components/modxmcp/` | Каталог ядра компонента (поддерживается и `[[++core_path]]`). Используется при загрузке API и определении версии. Меняйте только при нестандартной установке; неправильный путь нарушит работу API. |

## Безопасный порядок подключения

1. Установите пакет для вашей версии MODX. При новой установке `modxmcp.enabled=0`, токен создаётся автоматически; при обновлении существующий токен сохраняется.
2. Проверьте HTTPS, при необходимости список IP, прокси и `service_user_id`.
3. Скопируйте токен из панели в защищённое хранилище MCP-клиента; не публикуйте его.
4. Оставьте доступными только нужные функции. `allow_run_processor` и `allow_root_filesystem_read` без необходимости не включайте.
5. Включите API и проверьте **авторизованную операцию чтения**. Ответ `GET` о версии не доказывает, что токен клиента подходит.
