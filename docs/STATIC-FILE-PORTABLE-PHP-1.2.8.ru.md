# Static files: переносимый PHP — MODX MCP 1.2.8

Этот документ заменяет историческое описание staged-rename для существующих файлов. Актуальный контракт: [единый файловый backend](STATIC-IO-MODES-1.2.8.ru.md) и [ограничения безопасности](SECURITY-LIMITATIONS-1.2.8.ru.md).

Штатный portable обновляет существующий inode через PHP с flock, fstat/lstat, полной записью, ftruncate и fflush. Python, proc_open, FFI и новые серверные программы не нужны. Новые файлы публикуются после staging; конечные симлинки и hard links отклоняются. Существующая запись не атомарна: возможны частичные данные при аварии и внешние гонки. При неопределённом результате проверять фактическое состояние, не повторять автоматически. Экспериментальный strict остаётся явно выбираемым, не обязательным и не включается автоматически.
