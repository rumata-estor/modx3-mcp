## MODX 2

Проверка выполнена на чистой установке MODX 2.8.9-pl.

- проверка транспортного пакета: **пройдена** для сборки, чистой установки, CRUD через API, повторной установки с сохранением настроек, полного удаления и финальной установки;
- для v1.2.0 совпадение всех 81 действий только для чтения: **пройдено**; отсутствующие на чистом сайте фикстуры элементов пропускаются в матрице чтения и отдельно покрываются тестами жизненного цикла элементов;
- совпадение изменяющих операций: **пройдено**, 46 проверок для 39 generic processor mutations и отдельного `set_lexicon_entry`;
- жизненный цикл элементов: **пройден** для всех 7 поддерживаемых типов;
- наборы свойств: 5/5; ресурсы и служебные операции: 6/6 безопасных действий; системные настройки/TV/служебные операции: 8/8; источники файлов: 9/9; управление пакетами: 5/5;

Статус: **основная среда выполнения и релизная сборка проверены на работающем MODX 2.8.9-pl**.
