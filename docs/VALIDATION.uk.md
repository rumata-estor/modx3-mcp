# Перевірка версії 1.2.4 — MODX MCP

## 1.2.5 — source validation

Перевірки коду 1.2.5 охоплюють PHP, сумісність MODX 2/3 та шість команд modCategory. Транспортні ZIP 1.2.5 ще не перевірені реальною установкою.
