## О компоненте

MODX MCP подключает ИИ-агентов к MODX Revolution 2.8.x через HTTP API сайта и локальный MCP-клиент. Общий контракт MODX 2/3 содержит **193 серверных действия, из которых 192 — публичные инструменты MCP**: работа с ресурсами, шаблонами, чанками, сниппетами, TV, настройками и ClientConfig; анализ зависимостей, предварительная проверка изменений, резервное копирование и аудит. Этот транспортный пакет предназначен **только для MODX 2**.

## Установка и обновление

1. Установите `modx2mcp-1.2.4-pl.transport.zip` через менеджер пакетов MODX 2.8.x.
2. **Если ранее установлен старый пакет `modxmcp` для MODX 2:** предварительно полностью удалите его и затем установите `modx2mcp`. Это разные имена пакета, совместная установка не поддерживается. Полное удаление прежнего пакета удаляет также настройки `modxmcp.*` и API-токен: заранее сохраните нужную конфигурацию и после установки обновите токен в MCP-клиенте.
3. **При обновлении уже установленного `modx2mcp`:** используйте обычное обновление. Настройки и действующий токен сохраняются.
4. Новая установка по умолчанию **отключена**. Проверьте ограничения доступа и включите API в настройках дополнения.
5. На компьютере или сервере MCP-клиента требуется Node.js **18+**. Настройте запуск через `npx` и `github:rumata-estor/modx3-mcp#v1.2.4`.
6. Укажите `MODX_MCP_SITE_URL=https://your-site.example/assets/components/modxmcp/api.php` и секретный `MODX_MCP_TOKEN`. Используйте HTTPS. Сначала проверьте операцию чтения.

Подробности: [Установка](../INSTALL.ru.md), [Безопасность](../SECURITY.ru.md), [Проверки релиза](../VALIDATION.ru.md). Ответ на `GET` с номером версии **не подтверждает авторизацию**.

## Что нового в 1.2.4-pl

Полная локализация административной панели и графа зависимостей на **9 языков**: русский (`ru`), английский (`en`), испанский (`es`), немецкий (`de`), французский (`fr`), украинский (`uk`), казахский на кириллице (`kk`), нидерландский (`nl`) и польский (`pl`). Переведены 166 интерфейсных строк, включая управление API-токеном, группы возможностей, фильтры и диагностику графа.

Состав MCP API прежний: **193 серверных действия / 192 публичных инструмента**. Автоматического перевыпуска токена нет. Обычное обновление существующего пакета сохраняет настройки и токен.
