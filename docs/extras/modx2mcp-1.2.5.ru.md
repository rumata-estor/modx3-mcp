## О компоненте

MODX MCP подключает ИИ-агентов к MODX Revolution 2.8.x через HTTP API сайта и локальный MCP-клиент. Общий контракт MODX 2/3 содержит **199 серверных действий, из которых 198 — публичные инструменты MCP**: работа с ресурсами, шаблонами, чанками, сниппетами, TV, настройками и ClientConfig; анализ зависимостей, предварительная проверка изменений, резервное копирование и аудит. Этот транспортный пакет предназначен **только для MODX 2**.

## Установка и обновление

1. Установите `modx2mcp-1.2.5-pl.transport.zip` через менеджер пакетов MODX 2.8.x.
2. **Если ранее установлен старый пакет `modxmcp` для MODX 2:** предварительно полностью удалите его и затем установите `modx2mcp`. Это разные имена пакета, совместная установка не поддерживается. Полное удаление прежнего пакета удаляет также настройки `modxmcp.*` и API-токен: заранее сохраните нужную конфигурацию и после установки обновите токен в MCP-клиенте.
3. **При обновлении уже установленного `modx2mcp`:** используйте обычное обновление. Настройки и действующий токен сохраняются.
4. Новая установка по умолчанию **отключена**. Проверьте ограничения доступа и включите API в настройках дополнения.
5. На компьютере или сервере MCP-клиента требуется Node.js **18+**. Настройте запуск через `npx` и `github:rumata-estor/modx3-mcp#v1.2.4`.
6. Укажите `MODX_MCP_SITE_URL=https://your-site.example/assets/components/modxmcp/api.php` и секретный `MODX_MCP_TOKEN`. Используйте HTTPS. Сначала проверьте операцию чтения.

Подробности: [Установка](../INSTALL.ru.md), [Безопасность](../SECURITY.ru.md), [Проверки релиза](../VALIDATION.ru.md). Ответ на `GET` с номером версии **не подтверждает авторизацию**.

## Что нового в 1.2.5-pl

Исправлена неполная поддержка **категорий элементов MODX (modCategory)**. Добавлены шесть отдельных команд MCP: modx_list_categories, modx_get_category, modx_create_category, modx_update_category, modx_delete_category и modx_assign_element_category.

Теперь агент может создавать, переименовывать, вкладывать, перемещать и сортировать категории; назначать их чанкам, сниппетам, шаблонам, TV и плагинам **без переписывания кода элементов**. Удаление предварительно проверяет подкатегории, назначенные элементы и наборы свойств. Нельзя создать циклическую вложенность или удалить непустую категорию.

Новый контракт — **199 серверных действий / 198 публичных инструментов**. Поддерживаются MODX Revolution 2.8.x и 3.x. Обычные ресурсы и категории miniShop2 не затрагиваются.

**Обновление:** при штатном обновлении сохраняются действующие настройки и API-токен; миграция данных не требуется.
