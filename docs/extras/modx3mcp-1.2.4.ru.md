## О компоненте

MODX MCP подключает ИИ-агентов к MODX Revolution 3.x через HTTP API и локальный MCP-клиент. В компоненте **193 серверных действия, из которых 192 — публичные инструменты MCP**: управление ресурсами, шаблонами, чанками, сниппетами, TV, настройками и ClientConfig; граф зависимостей, проверки перед записью, резервное копирование и аудит. Этот транспортный пакет предназначен **только для MODX 3**; для MODX 2 существует отдельный MODX2MCP.

## Установка и обновление

1. Установите `modx3mcp-1.2.4-pl.transport.zip` через менеджер пакетов MODX 3 или обновите существующий пакет `modx3mcp`. При обычном обновлении существующие настройки `modxmcp.*` и API-токен сохраняются.
2. При новой установке API **отключён по умолчанию**. Проверьте безопасность и включите компонент в его настройках, получите токен от авторизованного администратора.
3. На компьютере или сервере MCP-клиента требуется Node.js **18+**. Настройте запуск `npx` с `github:rumata-estor/modx3-mcp#v1.2.4`.
4. Укажите `MODX_MCP_SITE_URL=https://your-site.example/assets/components/modxmcp/api.php` и секретный `MODX_MCP_TOKEN`. Используйте HTTPS.
5. Перезапустите MCP-клиент и сначала проверьте авторизованный запрос чтения; только затем включайте операции записи.

Подробности: [Установка](../INSTALL.ru.md), [Безопасность](../SECURITY.ru.md), [Проверки релиза](../VALIDATION.ru.md). Ответ `GET` с номером версии **не проверяет авторизацию**.

## Что нового в 1.2.4-pl

Полная локализация административной панели и графа зависимостей на **9 языков**: русский (`ru`), английский (`en`), испанский (`es`), немецкий (`de`), французский (`fr`), украинский (`uk`), казахский на кириллице (`kk`), нидерландский (`nl`) и польский (`pl`). Переведены 166 интерфейсных строк, включая управление API-токеном, группы возможностей, фильтры и диагностику графа.

Состав MCP API прежний: **193 серверных действия / 192 публичных инструмента**. Автоматического перевыпуска токена нет. Обычное обновление существующего пакета сохраняет настройки и токен.
