## О компоненте

MODX MCP подключает ИИ-агентов к MODX Revolution 3.x через HTTP API и локальный MCP-клиент. В компоненте **199 серверных действий, из которых 198 — публичные инструменты MCP**: управление ресурсами, шаблонами, чанками, сниппетами, TV, настройками и ClientConfig; граф зависимостей, проверки перед записью, резервное копирование и аудит. Этот транспортный пакет предназначен **только для MODX 3**; для MODX 2 существует отдельный MODX2MCP.

## Установка и обновление

1. Установите `modx3mcp-1.2.5-pl.transport.zip` через менеджер пакетов MODX 3 или обновите существующий пакет `modx3mcp`. При обычном обновлении существующие настройки `modxmcp.*` и API-токен сохраняются.
2. При новой установке API **отключён по умолчанию**. Проверьте безопасность и включите компонент в его настройках, получите токен от авторизованного администратора.
3. На компьютере или сервере MCP-клиента требуется Node.js **18+**. Настройте запуск `npx` с `github:rumata-estor/modx3-mcp#v1.2.4`.
4. Укажите `MODX_MCP_SITE_URL=https://your-site.example/assets/components/modxmcp/api.php` и секретный `MODX_MCP_TOKEN`. Используйте HTTPS.
5. Перезапустите MCP-клиент и сначала проверьте авторизованный запрос чтения; только затем включайте операции записи.

Подробности: [Установка](../INSTALL.ru.md), [Безопасность](../SECURITY.ru.md), [Проверки релиза](../VALIDATION.ru.md). Ответ `GET` с номером версии **не проверяет авторизацию**.

## Что нового в 1.2.5-pl

Исправлена неполная поддержка **категорий элементов MODX (modCategory)**. Добавлены шесть отдельных команд MCP: modx_list_categories, modx_get_category, modx_create_category, modx_update_category, modx_delete_category и modx_assign_element_category.

Теперь агент может создавать, переименовывать, вкладывать, перемещать и сортировать категории; назначать их чанкам, сниппетам, шаблонам, TV и плагинам **без переписывания кода элементов**. Удаление предварительно проверяет подкатегории, назначенные элементы и наборы свойств. Нельзя создать циклическую вложенность или удалить непустую категорию.

Новый контракт — **199 серверных действий / 198 публичных инструментов**. Поддерживаются MODX Revolution 2.8.x и 3.x. Обычные ресурсы и категории miniShop2 не затрагиваются.

**Обновление:** при штатном обновлении сохраняются действующие настройки и API-токен; миграция данных не требуется.
